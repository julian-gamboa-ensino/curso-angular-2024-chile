## Sobre o Projeto

O Jogo da Memória é uma aplicação web desenvolvida em Angular que implementa o clássico jogo de memória com emojis. O jogo inclui recursos como:

- Interface responsiva e moderna
- Animações suaves
- Sistema de pontuação
- Armazenamento local de recordes
- Suporte a SSR (Server-Side Rendering)
- Acessibilidade
